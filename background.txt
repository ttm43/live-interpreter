# 会议背景 —— 写给会议助手看的资料，随时编辑，保存后下一段分析立即生效。
# 以 # 开头的行是注释，不会发给模型。可以在开会前填好，也可以会中随时补充。
#
# 建议写（用中文或英文都行）：
#   - 这是什么会：项目、议程、要决定什么
#   - 与会者：名字、角色、和你的关系（谁是你老板、谁是客户）
#   - 项目现状：进展、卡点、上次会议的结论
#   - 你的目标：这次会你想推动什么、想避免什么、你的底线
#
# 示例（删掉换成你自己的）：
#   Weekly sync of the billing migration project.
#   参会者: David (my manager), Sarah (QA lead), Tom (client side PM).
#   现状: 迁移完成 80%，剩 200 个 legacy 账户；上周发现数据对账 bug 已修复。
#   我的目标: 争取把 deadline 从季度末推迟两周；避免当场承诺具体日期。
